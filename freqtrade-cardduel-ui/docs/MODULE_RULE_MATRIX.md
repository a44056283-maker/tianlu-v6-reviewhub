# 模块与子规则矩阵

## 页面级模块

| 页面类别 | 模块 | 风格名称 | 保留功能 |
| --- | --- | --- | --- |
| Auth | 登录表单 | 召唤契约 | API 地址、用户名、密码、记住登录 |
| Bot Hub | Bot 列表 | 召唤大厅 | Bot 选择、编辑、新增、连接状态 |
| Dashboard | 指标卡 | 战绩卡 | 资产、收益、开仓、状态 |
| Dashboard | 图表 | 战场曲线 | ECharts/资产曲线 |
| Trade | 交易对卡 | 场上卡牌 | Pair、价格、涨跌、详情 |
| Chart | K 线 | 符文地图 | K线、买卖点、指标、周期 |
| Orders | 表格 | 指令表 | 订单状态、取消、详情 |
| Balance | 余额表 | 金库表 | 可用、冻结、估值、占比 |
| Strategy | 策略卡 | 牌组卡 | 启用、胜率、交易数、收益 |
| Strategy Rule | 规则编辑 | 符文面板 | 条件、参数、开关、保存 |
| Backtest | 回测结果 | 试炼战绩 | 总收益、胜率、回撤、交易明细 |
| Logs | 日志流 | 战报中心 | INFO/WARNING/ERROR、搜索、筛选 |
| Settings | 设置表单 | 符文书 | 基础、交易所、通知、安全、外观 |

## 策略子规则

| 子规则模块 | 规则项 | 桌面行为 | 移动端行为 | 备注 |
| --- | --- | --- | --- | --- |
| 基础符文 | 策略名称、交易模式、交易对、时间周期、最大开仓、初始资金 | 双栏表单 + 预览卡 | 单列表单 | 不改策略字段 |
| 买入进攻符文 | RSI、MACD、成交量、EMA、突破、冷却 | 左侧规则列表 + 右侧卡牌预览 | 折叠规则组 | AND/OR 逻辑保留 |
| 卖出斩杀符文 | ROI、RSI 超买、MACD 死叉、移动止盈、时间止盈、反向信号 | 阶梯式规则面板 | 单列步骤卡 | 平仓确认不弱化 |
| 风控护盾符文 | 止损、回撤、单日亏损、异常波动、最大连续亏损、确认弹窗 | 风险红框 + 二次确认提示 | 固定底部风险按钮 | 危险操作必须确认 |
| 仓位规则 | 固定仓位、动态仓位、风险比例、最大持仓、资金保留、复利模式 | 参数卡 + 滑块 | 单列参数卡 | 不保存敏感信息 |
| 时间与数据 | Timeframe、Startup candles、交易时段、禁止时段、数据源、缓存 | 时间轴控件 | 横向滑动胶囊 | 与数据下载联动 |
| FreqAI | 训练开关、特征选择、模型周期、置信度、回测验证、漂移检测 | AI 状态面板 | 状态摘要 + 详情页 | 仅 UI，不训练模型 |
| 代码卷轴 | indicators、entry、exit、参数注入、语法检查、版本回滚 | 代码编辑器桌面优先 | 移动端只读预览 | 编辑建议桌面端 |
| 回测配置 | 交易所、区间、手续费、滑点、初始资金、导出报告 | 配置侧栏 + 曲线 | 配置折叠 + 曲线卡 | 保留 FreqUI 回测逻辑 |
| 通知确认 | 强制平仓确认、StopEntry、Telegram、Webhook、邮件、审计日志 | 安全开关表 | 开关卡片 | 不暴露 Token 原文 |

## 验收要求

- 所有交易/平仓/取消订单按钮必须继续走原确认逻辑。
- 所有 Token/API Key 字段只显示占位，不允许在 UI 设计包中写入真实密钥。
- 移动端不得隐藏核心风险状态。
- 表格在移动端变卡片，不横向溢出核心操作按钮。
