```
噪音过滤准确率 = (标记为HIGH_NOISE且后续验证为亏损的交易数) / (标记为HIGH_NOISE的总交易数)
```

- QUALITY信号: 266条
- 噪音过滤效果: **无法从影子数据直接计算**（影子实验不执行实际交易）

**建议回测口径**:
- 在 `flow_gate_backtest.py` 中用历史数据回测，定义:
  - True Positive（正确拦截）: 影子标记HIGH_NOISE且后续价格反向
  - False Positive（误拦截）: 影子标记HIGH_NOISE但后续价格同向
  - 噪音过滤召回率: 需要建立历史对照基准

### 3.2 误入场率

```
误入场率 = (影子实验标记为observe但实盘执行了入场) / (总观察信号数)
```

当前影子数据中:
- observe信号: 3040 - 285 = 2755条（增强版）
- 误入场定义: 实盘在增强版判断observe时入场且亏损

**注意**: 当前为纯影子实验，无实盘对照，无法直接计算误入场率。需在 `flow_gate_backtest.py` 中用历史数据模拟。

### 3.3 误出场率

```
误出场率 = (影子实验建议hold但实盘执行了出场) / (总持仓评估样本数)
```
