## 2. 出场路径冲突可能性

### 优先级分析

```
优先级排序（由高到低）:
1. P3残留强制全平    → 跳过L1/L2/L3/L5检测
2. ATR止损          → 独立于盈利分批，可叠加
3. L1盈利分批       → 按盈利阈值分档（15%/20%/30%）
4. L5动态止盈       → 按S/R位置触发
5. L2时线止盈       → 与L5重叠但优先于L5
6. 自学习防御       → 错误率>50%+盈利触发
7. 舆情emergency    → 突发事件覆盖所有
```

### 潜在冲突点

| 冲突场景 | 代码证据 | 风险等级 |
|---------|---------|---------|
| L5 + L2同时触发 | `v65_autopilot.py:4415-4457` + `v65_autopilot.py:4736-4934` | 低 |
| ATR + L1分批叠加 | `v65_autopilot.py:4634-4639` 在L1检测前独立执行 | **中** |
| P3残留 + force_exit | `v65_autopilot.py:4578-4596` + `console_server.py:5087` | 低 |
| 自学习 + 正常止盈 | `v65_autopilot.py:4661-4675` 会收紧阈值 | **中** |

### 互斥锁机制

```python
# v65_autopilot.py:4614-4616
if pair in _pair_exit_done:
    _log(f"  ⏭️ {pair} 本周期已执行退出，跳过L1/L3/L5/L2检测")
    continue
```

**评估**: 存在互斥锁 `_pair_exit_done`，同周期内只允许一次退出执行。

## 3. 是否存在提前平仓风险

### 审计结论：**存在风险**

#### 提前平仓触发点

| 触发器 | 条件 | 风险描述 |
|-------|------|---------|
| 自学习微调 | 连续亏损≥2次+盈利>5% | 收紧止盈阈值到10%，盈利5%就开始卖 |
| L1分批(15%) | 10x杠杆=真实涨幅1.5% | 可能过早卖出 |
| ATR止损 | 紧贴ATR阈值 | 在强平线之前触发 |

#### 自学习防御代码

```python
# v65_autopilot.py:4671-4675
if consec_losses >= 2 and profit_pct > 5:
    thresh = 10  # 盈利>5%就开始卖
    _log(f"[自学习微调] {pair} 连续亏损{consec_losses}次，收紧止盈触发至{thresh}%")
    _temp_thresh_override[base] = thresh
```

**风险**: 连续亏损2次后，盈利5%就触发卖出，可能错过后续大涨。

### 提前平仓归因逻辑

```python

"继续把L5样本与真实订单盈亏做胜率/提前平仓归因"
```

### ATR动态止损

```python
# v65_autopilot.py:4460-4470
ATR止损 vs 强平止损，取更保守（更紧）的值
```
